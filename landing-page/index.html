Pertanyaan yang Sering Diajukan (FAQ)

Semua hal yang perlu kamu ketahui tentang keamanan, izin, dan update Jajan Tracker.

Apakah aplikasi ini aman dan bebas malware?
Sangat aman. Jajan Tracker adalah proyek open-source dengan lisensi MIT. Kode sumber kami 100% transparan dan dapat diaudit secara publik di GitHub. Aplikasi ini bahkan tidak meminta izin android.permission.INTERNET di AndroidManifest, sehingga secara teknis mustahil bagi aplikasi untuk mengirimkan data ke pihak ketiga.
Kenapa aplikasi meminta izin Layanan Aksesibilitas (Accessibility)?
Izin Accessibility Service murni digunakan untuk mendeteksi kapan aplikasi Shopee atau scanner QRIS dibuka, sehingga sistem dapat memunculkan floating chip pengingat saldo selama 6 detik. Aplikasi sama sekali tidak membaca teks ketikan keyboard, password, ataupun chat pribadi.
Bagaimana cara update aplikasi ke versi baru tanpa kehilangan riwayat jajan?
Kamu cukup mengunduh file APK versi terbaru dan menginstalnya langsung tanpa mencopot (uninstall) versi lama. Android akan otomatis menimpa file aplikasi, dan semua database SQLite lokal yang berisi catatan pengeluaranmu akan tetap utuh 100%.
Apakah aplikasi ini membutuhkan koneksi internet?
Tidak sama sekali! Jajan Tracker bekerja 100% offline. Semua catatan pengeluaran tersimpan rapi di database SQLite lokal di penyimpanan internal HP kamu. Tidak ada sinkronisasi cloud atau risiko kebocoran data.
Apakah tersedia untuk perangkat iOS / iPhone?
Saat ini Jajan Tracker berfokus untuk Android karena fitur utama kami — Home Screen Widget 4x2 interaktif dengan 1-Tap Log serta Floating Overlay ShopeePay Nudge — membutuhkan native Android APIs yang tidak didukung oleh iOS.

Siap Mengendalikan Pengeluaran Jajanmu?

Pasang Jajan Tracker sekarang, pasang widget di layar depan HP, dan nikmati kemudahan mencatat tanpa ribet.
