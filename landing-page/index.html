0-Friction Logging

Catat Pengeluaran dalam < 2 Detik

Gak perlu pusing milih dropdown kategori atau ngisi form panjang. Cukup ketik nominal lewat numpad cepat dengan tombol preset favorit, selesai seketika.

Numpad Custom & Preset Instant

Dilengkapi tombol sekali sentuh: +5rb, +10rb, +20rb, +50rb, dan 000. Nyatat cilok atau kopi susu gak pernah secepat ini.

Mental Accounting

Pisahkan Uang Pokok (sewa, tagihan, tabungan) dari Uang Jajan. Nikmati jajanmu tanpa rasa bersalah karena uang wajib sudah aman.

Tanpa Login, Tanpa Akun

Buka aplikasi dan langsung gunakan. Kami tidak pernah meminta email, password, nomor HP, apalagi sinkronisasi rekening bank.

100% Offline & Tersimpan Lokal

Semua catatan tersimpan di database SQLite perangkat HP kamu. Tidak ada data yang dikirim ke server internet.

Pertanyaan yang Sering Diajukan (FAQ)

Apakah aplikasi ini aman untuk dipasang?

Sangat aman. Jajan Tracker adalah aplikasi open source tanpa koneksi server, tanpa tracking, dan tidak mengirim data pengeluaranmu ke pihak mana pun.

Kenapa butuh izin Layanan Aksesibilitas?

Izin Accessibility Service murni digunakan untuk mendeteksi saat aplikasi Shopee atau scanner QRIS dibuka, sehingga aplikasi dapat memunculkan floating banner saldo. Aplikasi tidak membaca ketikan keyboard, password, ataupun chat.

Apakah butuh koneksi internet?

Tidak sama sekali! Jajan Tracker bekerja 100% offline. Semua catatan pengeluaran tersimpan rapi di database SQLite lokal di memori HP kamu.

Apakah tersedia untuk perangkat iOS / iPhone?

Saat ini Jajan Tracker berfokus untuk Android karena fitur interaktif Home Screen Widget dan Floating Overlay ShopeePay memerlukan native Android APIs.

Siap Mengendalikan Pengeluaran Jajanmu?

Pasang Jajan Tracker sekarang, pasang widget di layar depan HP, dan nikmati kemudahan mencatat tanpa ribet.
