3 Langkah Mudah Pasang APK di Android

Sideloading di Android sangat cepat dan aman. Ikuti panduan singkat 3 langkah berikut:

01 Unduh File APK

Ketuk tombol download di atas. Jika Google Chrome menampilkan peringatan "File mungkin berbahaya", pilih Tetap Unduh (ini adalah peringatan umum Android untuk file mandiri).

02 Izinkan Sumber Ini

Buka file app-release.apk yang baru diunduh. Pada pop-up proteksi Android, ketuk Setelan lalu aktifkan toggle Izinkan dari sumber ini.

03 Pasang & Tambah Widget

Pilih Install. Setelah selesai, buka aplikasi, tahan layar utama HP (Home Screen), pilih menu Widget, lalu pasang Jajan Tracker 4x2!

Pertanyaan yang Sering Diajukan (FAQ)

Semua hal yang perlu kamu ketahui tentang keamanan APK, izin aksesibilitas, dan update Jajan Tracker.

Apakah aplikasi ini aman dan bebas malware?
Sangat aman. Jajan Tracker adalah proyek open-source dengan lisensi MIT. Kode sumber kami 100% transparan dan dapat diaudit secara publik di GitHub. Aplikasi ini bahkan tidak meminta izin android.permission.INTERNET di AndroidManifest, sehingga secara teknis mustahil bagi aplikasi untuk mengirimkan data keuangan Anda ke pihak mana pun.
Kenapa aplikasi meminta izin Layanan Aksesibilitas (Accessibility)?
Izin Accessibility Service murni digunakan untuk mendeteksi kapan aplikasi Shopee atau scanner QRIS dibuka, sehingga sistem dapat memunculkan floating chip pengingat saldo selama 6 detik. Aplikasi sama sekali tidak membaca teks ketikan keyboard, password, ataupun riwayat chat pribadi Anda.
Bagaimana cara update aplikasi ke versi baru tanpa kehilangan data?
Anda cukup mengunduh file APK versi terbaru dan menginstalnya langsung tanpa mencopot (uninstall) versi lama. Android akan otomatis memperbarui aplikasi, dan semua database SQLite lokal yang berisi catatan pengeluaran Anda akan tetap utuh 100%.
Apakah aplikasi ini membutuhkan koneksi internet?
Tidak sama sekali! Jajan Tracker bekerja 100% offline. Semua catatan pengeluaran tersimpan rapi di database SQLite lokal di penyimpanan internal HP kamu. Tidak ada sinkronisasi cloud atau risiko kebocoran data.
Apakah tersedia untuk perangkat iOS / iPhone?
Saat ini Jajan Tracker berfokus untuk Android karena fitur utama kami — Home Screen Widget 4x2 interaktif dengan 1-Tap Log serta Floating Overlay ShopeePay Nudge — membutuhkan native Android APIs yang tidak didukung oleh iOS.
